# UCI Banknote Authentication dataset

`banknote_authentication.csv` is the external dataset used in the experiment.

- Source: UCI Machine Learning Repository
- Dataset: Banknote Authentication
- Creator: Volker Lohweg
- DOI: https://doi.org/10.24432/C55P57
- License: CC BY 4.0
- Instances: 1,372
- Features: 4
- Target classes: 2
- Missing values: none

The five columns contain variance, skewness, curtosis, entropy, and the class label.
